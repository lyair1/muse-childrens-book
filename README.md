# muse-childrens-book

A Muse skill that makes a custom illustrated children's picture book starring your own kid and family — end to end, from parent interview to a virtual flip-book or a Lulu-printed hardcover.

Start at **SKILL.md**. Supporting detail lives in `references/`:

- `lulu-print-specs.md` — Lulu trim, paper, ink, and file requirements
- `story-patterns.md` — page-plan templates and the shame-free behavioral story arc
- `field-notes.md` — diary of the first production run: every decision, fix, and lesson
- `virtual-preview.md` — how to build the CSB-style page-flip web artifact

Built from a real production run — one proof copy ordered September 2026.
